---

## Download Instructions

1. Go to: **https://doi.org/10.5281/zenodo.7693648**
2. Click **"Download all"** or download each `.xlsx` file individually
3. Place all `.xlsx` files in **this folder** (`data/`)

After downloading, this folder should look like:
```
data/
├── A001.xlsx
├── A002.xlsx
├── A003.xlsx
├── ...
└── A826.xlsx  (826 total files)
```

## Dataset Description

- **826 incremental exercise tests** across 4 sports
- Collected at Human Performance Laboratory, School of Medicine, Trinity College Dublin, Ireland
- Each file is one athlete test containing:
  - Sheet 1: Athlete metadata (sport, age, height, weight, sex)
  - Sheet 2: Stage-by-stage HR and blood lactate data
  - Sheet 3: Derived metrics including HRmax and HR @ 2 mmol/L (LT)

| Sport | N |
|-------|---|
| Running | 281 |
| Cycling | 280 |
| Rowing | 210 |
| Kayak | 54 |
| **Total** | **825** (after quality filtering) |
